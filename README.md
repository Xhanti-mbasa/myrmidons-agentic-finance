## Develop

Requires Node 22 (see `.nvmrc`) and pnpm.

```bash
pnpm install
pnpm typecheck
pnpm test
```

`services/agent/TESTING.md` explains how the agent tests work: a scripted hostile model and a fake backend that records every request.
